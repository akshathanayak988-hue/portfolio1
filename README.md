# Akshatha – Portfolio

Vite project built from the original Claude portfolio (design and interactions unchanged).

## Commands

    npm install
    npm run dev        # http://localhost:5173
    npm run build      # output in dist/
    npm run preview    # serve the built site

## Deploy on Vercel

Push to GitHub, import the repo in Vercel (framework: Vite, build `npm run build`, output `dist`), then Deploy.

## Edit content

Projects: `PROJECTS` list at the top of `src/main.js`. Page text: `index.html`. Styles: `src/style.css`.
